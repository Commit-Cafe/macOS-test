# SilentBackup - 静默文件备份工具

## 项目背景

在公司日常业务中，客户来访时经常需要通过以下方式分享文件：

- **微信传输助手**：客户通过微信PC版发送文件到公司电脑
- **U盘拷贝**：客户携带U盘，将文件复制到公司电脑

客户使用完文件后会自行删除，但这些文件对公司有留存价值。需要在客户操作期间，**静默、无感知地**自动备份这些文件，确保文件不丢失。

---

## 项目目标

| 目标 | 说明 |
|------|------|
| **无感知** | 程序在后台静默运行，客户操作电脑时完全无察觉 |
| **全来源覆盖** | 同时覆盖微信文件、U盘文件、桌面/下载目录 |
| **去重存储** | 通过 MD5 哈希避免重复备份同一文件 |
| **隐蔽存储** | 备份文件存放在隐藏目录中，Finder 中不可见 |
| **简单易用** | 一键启动/停止，无需复杂配置 |

---

## 实现效果

### 工作流程

```
客户到来 → 双击启动.command → 菜单栏点击"启动备份" → 客户操作电脑（微信传文件/U盘拷贝）→ 程序后台静默备份 → 客户离开 → 菜单栏点击"停止备份"
```

### 功能模块

#### 1. 微信文件监控

- 自动发现 macOS 微信PC版的文件存储路径
  - `~/Library/Containers/com.tencent.xinWeChat/Data/Library/Application Support/com.tencent.xinWeChat/`
- 使用 `watchdog` 库实时监控目录变化
- 检测到新文件写入后延迟 2 秒（等待文件写入完成），然后静默复制

#### 2. U盘/外接磁盘检测

- 每 2 秒轮询扫描 `/Volumes/` 目录
- 自动排除 `Macintosh HD`（系统盘）
- 检测到新磁盘插入后等待 3 秒（等待磁盘挂载完成），然后全盘扫描复制
- 自动跳过 `.` 开头的隐藏文件和系统文件

#### 3. 桌面/下载目录监控

- 监控 `~/Desktop` 和 `~/Downloads` 目录
- 作为兜底方案，捕获客户从U盘粘贴到这些位置的文件

#### 4. 文件去重

- 对已存在的备份文件进行 MD5 哈希比对
- 内容完全相同的文件不会重复备份
- 同名不同内容的文件自动重命名（`文件名_1.ext`、`文件名_2.ext`）

#### 5. 隐蔽存储

- 备份根目录：`/Users/shared/.silent_backup_data/`
- 以 `.` 开头，macOS Finder 默认不显示
- 额外使用 `chflags hidden` 设置隐藏属性，双重保障
- 按日期和来源分类存储：

```
/Users/shared/.silent_backup_data/
├── 2026-05-22/
│   ├── wechat/        ← 微信文件
│   │   ├── 合同文件.pdf
│   │   └── 产品报价.xlsx
│   ├── usb/           ← U盘文件
│   │   ├── 客户资料.docx
│   │   └── 设计稿.psd
│   ├── desktop/       ← 桌面文件
│   └── downloads/     ← 下载文件
```

#### 6. GUI 界面

- 窗口标题显示为"系统维护工具"，不暴露真实用途
- 深色主题界面，简洁低调
- 实时显示今日备份文件数量
- 运行日志记录到 `backup.log`

## 使用方法

### 首次部署

```bash
# 1. 安装依赖
pip3 install -r requirements.txt

# 2. 给启动脚本执行权限
chmod +x 启动.command
chmod +x stop.command
```

### 日常使用

1. 双击 `启动.command` 启动程序，程序会在菜单栏显示一个 🔧 图标
2. 点击菜单栏图标，右键选择 **"启动备份"**
3. 客户操作完毕后，右键选择 **"停止备份"**
4. 备份文件在 `/Users/shared/.silent_backup_data/日期/` 目录下查看

### 菜单栏说明

| 菜单项 | 说明 |
|--------|------|
| 🔧 图标 | 点击可查看状态，右键打开菜单 |
| 启动备份 | 开始监控并备份文件 |
| 停止备份 | 停止所有监控 |
| 状态: 运行中/已停止 | 当前备份引擎状态 |
| 今日备份: X 个文件 | 当日已备份文件数量 |
| 退出 | 完全退出程序 |

### macOS 权限

首次运行需要在「系统偏好设置 → 安全性与隐私」中授予：
- **完全磁盘访问权限**（访问微信文件目录）
- **可移动卷访问权限**（读取U盘文件）

## 配置说明

编辑 `config.json` 可自定义以下参数：

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `backup_root` | `/Users/shared/.silent_backup_data` | 备份文件存储根目录 |
| `watch_dirs.desktop` | `true` | 是否监控桌面 |
| `watch_dirs.downloads` | `true` | 是否监控下载目录 |
| `watch_dirs.wechat` | `true` | 是否监控微信文件 |
| `usb_monitor` | `true` | 是否监控U盘 |
| `file_extensions.exclude` | `.tmp`, `.temp` 等 | 排除的文件类型 |
| `file_extensions.include` | 空（全部） | 仅备份这些类型（空=不限） |
| `max_file_size_mb` | `500` | 单文件最大大小 |
| `copy_delay_seconds` | `2` | 检测到文件后延迟复制秒数 |

## 注意事项

### 法律声明与使用前提

**本工具仅供公司内部合法使用。**

在使用本工具前，请确保满足以下条件：

1. **客户协议告知**：在客户协议或来访登记表中明确告知"本公司电脑装有文件备份系统"
2. **合规场景**：仅在公司业务场景下使用（如客户文件留存），禁止用于任何非法目的
3. **数据保护**：备份文件包含客户敏感信息，需妥善保管，不得对外泄露
4. **定期清理**：建议定期清理过期备份数据，避免数据堆积

**本工具开发者不对任何滥用行为承担任何责任。**

### 其他注意事项

1. 程序运行日志保存在 `backup.log` 中，可用于审计
2. 备份目录设置为隐藏，防止普通用户误操作
3. 程序以当前用户权限运行，无法备份其他用户的数据
